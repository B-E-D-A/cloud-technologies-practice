# Облачные технологии - Практическая работа №6

Автоматизировать процесс создания образа виртуальной машины с приложением и необходимыми сервисами, используя инструменты Packer и Ansible

### Образ включает:

* Установленную операционную систему (Ubuntu)
* Код приложения (Flask/Python)
* Веб-сервер (Nginx)

Конфигурация выполняется через механизм provisioning'а Ansible.
Пример Ansible-конфигурации - https://www.geeksforgeeks.org/devops/deploy-a-flask-web-app-with-nginx-postgresql-using-ansible/

Перед сборкой образа необходимо создать в корне проекта файл `key.json` с ключом сервисного аккаунта Yandex Cloud

Образ создается при помощи команды `packer build .`
